# 📁 Dotfiles :p

Welcome to my personal configuration repository. This repo contains my environment settings for Bash, Vim, Fastfetch, and Konsole.

## 🛠️ Highlights

* **Vim & Bash**: Optimized aliases and workflow tweaks.
* **Fastfetch**: Custom `jsonc` configuration featuring a **1/5 chance** to display a random ASCII meme from the `assets/logos` folder.
* **Konsole**: Custom profile and bookmark management.
* **Assets**: A curated collection of wallpapers and custom terminal logos.

---

## 📂 Folder Structure

```text
.
├── assets
│   ├── logos             # ASCII art and logos
│   └── wallpapers        # Desktop backgrounds
├── fastfetch
│   └── config.jsonc      # Main fetch config
├── konsole_configs
│   ├── bookmarks.xml     # Terminal bookmarks
│   └── profile           # Konsole appearance/behavior
├── bashrc                # Bash aliases and functions
└── vimrc                 # Vim editor configuration

```

---

## 🚀 Installation

I use symbolic links (`ln -s`) to map these files to their respective locations in the home directory.

> [!WARNING]
> Always back up your existing config files before running these commands!

### 1. Bash & Vim

```bash
ln -sf ~/dotfiles/bashrc ~/.bashrc
ln -sf ~/dotfiles/vimrc ~/.vimrc

```

### 2. Fastfetch

```bash
mkdir -p ~/.config/fastfetch
ln -sf ~/dotfiles/fastfetch/config.jsonc ~/.config/fastfetch/config.jsonc

```

### 3. Konsole

```bash
mkdir -p ~/.local/share/konsole
ln -sf ~/dotfiles/konsole_configs/profile ~/.local/share/konsole/MyProfile.profile
ln -sf ~/dotfiles/konsole_configs/bookmarks.xml ~/.local/share/konsole/bookmarks.xml

```

## 🎨 Features

### **The "Meme Roulette" (Fastfetch)**

The Fastfetch configuration is set up to keep the terminal interesting. Every time a new shell is opened, there is a **20% chance** that instead of the standard system logo, you’ll be greeted by a random ASCII meme stored in `assets/logos`.

### **Bash Aliases**

Some of my most used shortcuts included in `bashrc`:

* `ll`: Long format directory listing.
* `c`: Quick `clear`.
* `close`: Shuting down the system
